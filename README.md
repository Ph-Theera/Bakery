# Olive & Oven

เดโมหน้าร้านเบเกอรี่ภาษาไทยสำหรับ Olive & Oven พร้อมโหมด Admin Demo

## วิธีเปิด

เปิด `index.html` ในเบราว์เซอร์ได้ทันที หรือรัน static server เช่น `npx serve .`

## ฟีเจอร์ในเดโม

- หน้าร้าน responsive พร้อมค้นหาและกรองหมวดหมู่
- ตะกร้าสินค้า เพิ่ม/ลด/ลบรายการ และบันทึกด้วย localStorage
- Checkout แบบย่อพร้อมสร้าง Order ID และประวัติคำสั่งซื้อ
- Admin Demo: KPI, กราฟยอดขาย, รายการสินค้า, ปรับสต็อก, ตารางออเดอร์ และตั้งค่าร้าน
- ปุ่มรีเซ็ตข้อมูลเดโม

ข้อมูลทั้งหมดเป็นข้อมูลจำลองในเบราว์เซอร์ ยังไม่มี backend, payment gateway, หรือการยืนยันสิทธิ์ผู้ดูแลจริง
